# PICO 4 Paper Tracker — автозапуск

Magisk-модуль, который автоматически запускает **Bridge Paper Tracker** (`com.bridge.papertracker`) на PICO 4 (A8110) после загрузки.

> 中文: [README.md](README.md) · English: [README.en-US.md](README.en-US.md)

## Возможности

- Ждёт завершения загрузки системы (`sys.boot_completed`).
- Дополнительно ждёт стабилизации рендеринга / vrshell и выхода из **see-through** (прозрачного режима) / первой настройки лаборатории перед запуском.
- Запускает `com.bridge.papertracker` с повторами (до 5 попыток).
- Переключатель без правки скриптов: включение / отключение на лету.

## Требования

- PICO 4 (A8110), с root
- Установлен Magisk (с поддержкой модулей)
- Установлено приложение Paper Tracker (`com.bridge.papertracker`)

## Установка

1. Упакуйте каталог модуля в zip (или сам каталог) и установите через Magisk Manager (`Install from storage`):

   ```
   adb push paper_autostart.zip /sdcard/
   # затем установите из этого zip в Magisk Manager
   ```

2. Перезагрузитесь. Paper Tracker запустится через ~15–25 с после загрузки.

## Настройка

Модуль читает файл `enable` в собственном каталоге: `1` (включить) или `0` (отключить). По умолчанию включён при первом запуске.

Запустите `toggle.sh` в каталоге модуля:

```sh
sh toggle.sh enable     # включить автозапуск
sh toggle.sh disable    # отключить автозапуск
sh toggle.sh            # показать справку
```

> Примечание: изменение `enable` вступает в силу при следующей перезагрузке.

## Структура

```
paper_autostart/
├── module.prop    # описание модуля Magisk
├── service.sh     # логика автозапуска (boot_completed + ожидание see-through + повторы)
└── toggle.sh      # скрипт включения/отключения
```

## Как это работает

`service.sh`:

1. Ждёт до 60 с, пока `sys.boot_completed=1`.
2. Ждёт ещё ~20 с, пока завершится see-through / настройка лаборатории, чтобы Paper не был заблокирован.
3. Запускает `com.bridge.papertracker` до 5 раз (с паузами), останавливаясь после обнаружения процесса.
